# C++ Data Structures and Algorithms Practice

A collection of basic C++ programs covering fundamental Data Structures and Algorithms (DSA) concepts. This repository contains solutions to basic problems involving arrays, strings, recursion, stacks, and linked lists.

## 📚 Topics Covered

* Arrays
* Searching
* Sorting
* Strings
* Recursion
* Stack
* Linked List

| No. | Program                              | File                           |

## 🛠️ Language Used

* **C++**
* Standard C++ Library (`iostream`, `string`, `stack`)

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/<repository-name>.git
   ```

2. Open any `.cpp` file in your preferred C++ IDE or editor.

3. Compile the program:

   ```bash
   g++ filename.cpp -o program
   ```

4. Run the executable:

   ```bash
   ./program
   ```
